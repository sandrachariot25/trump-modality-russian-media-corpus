# Отчёт о технической проверке / Integrity report

Дата: 13 ноября 2026 г.

| Показатель рабочего массива | Результат |
|---|---:|
| Оригинальные высказывания | 120 |
| Публикации СМИ | 160 |
| Сопоставления | 251 |
| Иллюстративные случаи разметки | 45 |
| Сопоставления с несуществующими statement_id | 0 |
| Сопоставления с несуществующими media_id | 0 |
| Примеры без соответствующей строки сопоставления | 0 |

Десять строк рабочего массива ссылаются на иной `statement_id`, чем *основная* привязка публикации в метаданных. Публикация может упоминать несколько высказываний; такие случаи требуют предметной проверки, а не автоматического исключения.

**Существенное ограничение:** подтверждённого реестра отбора итоговой выборки 112/144/223 нет. Опубликованные рабочие данные 120/160/251 не следует представлять как её точную копию.

Независимая человеческая экспертиза модальности, метрики согласованности кодировщиков и сплошная проверка русских публикаций по первоисточникам этим отчётом **не подтверждаются**.
