# Единицы учёта и разграничение рабочего массива и выборки статьи

Данные в этом репозитории представляют **расширенный рабочий массив**. Схема учёта основана на уникальных идентификаторах двух классов и на строках сопоставлений.

| Уровень | Определение | Рабочий массив GitHub | Аналитический срез статьи |
|---|---|---:|---:|
| Англоязычное высказывание | Уникальный `statement_id` | 120 | 112 |
| Высказывание с русскоязычным соответствием | `statement_id`, у которого есть хотя бы одна соответствующая публикация | 120 | 109 |
| Русскоязычная публикация | Уникальный `media_id` | 160 | 144 |
| Пара соответствий | Уникальная комбинация (`statement_id`, `media_id`) | 170 | 152 |
| Текстовое сопоставление | Одна строка, связывающая оригинал с конкретной цитатой, пересказом или заголовком | 251 | 223 |

Одна публикация может содержать несколько самостоятельных высказываний, а одна пара соответствий — несколько форм передачи. Поэтому число пар обычно больше числа публикаций, а число сопоставлений — числа пар.

**Важно:** числа аналитического среза 112/109/144/152/223 воспроизведены из рукописи. В опубликованной расширенной рабочей выгрузке пока **нет достоверного машиночитаемого фильтра включения/исключения** для получения именно этих итоговых строк. Разности 8/16/18/28 характеризуют объёмы двух наборов, но сами по себе не являются идентификаторами исключённых единиц. Частоты итоговой таблицы статьи нельзя независимо воспроизвести только по открытой рабочей выгрузке.

Техническая проверка 251 строки рабочего массива подтверждает валидность связей по ID, но не подтверждает экспертную семантическую классификацию 223 итоговых наблюдений. Независимое повторное кодирование человеком не заявлено.
