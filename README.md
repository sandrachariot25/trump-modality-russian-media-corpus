# Political modality in Russian-language media: working corpus

Электронное приложение к исследованию **«Модальность и категоричность высказываний Дональда Трампа в русскоязычном медиадискурсе» (2026)**.

## Состав

| Файл | Содержимое |
|---|---|
| [data/statements_metadata.csv](data/statements_metadata.csv) | 120 англоязычных высказываний: даты, жанры, темы, URL |
| [data/media_metadata.csv](data/media_metadata.csv) | 160 русскоязычных публикаций: метаданные и URL |
| [data/comparisons_annotations.csv](data/comparisons_annotations.csv) | 251 сопоставление и признаки семантических изменений |
| [data/sample_annotations.csv](data/sample_annotations.csv) | 45 примеров разметки |
| [methods/CODING_PROTOCOL.md](methods/CODING_PROTOCOL.md) | Правила классификации |
| [methods/VALIDATION_REPORT.md](methods/VALIDATION_REPORT.md) | Проверенные количественные показатели и ограничения |
| [verify_dataset.py](verify_dataset.py) | Скрипт контроля ссылочной целостности CSV |

## Важное различие между данными и статьёй

Репозиторий содержит **расширенный рабочий массив 120/160/251**, а статья опирается на **итоговый аналитический срез 112/144/223**. В доступных исходных материалах не сохранился полный построчный реестр включений и исключений для итогового среза. Поэтому этот репозиторий **не является полной воспроизводимой выгрузкой окончательной выборки статьи**, хотя позволяет изучить исходный рабочий материал и правила разметки.
